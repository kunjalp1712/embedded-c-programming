# Embedded C Programming

A collection of C programming concepts, practice programs, and mini-projects focused on building a strong foundation for Embedded Systems development.

## About This Repository

This repository contains my learning journey in C programming, with a focus on concepts that are useful for microcontrollers and embedded systems.

The goal is to understand C programming through practical examples rather than only theoretical concepts.

## Topics Covered

- Variables and Data Types
- Operators
- Conditional Statements
- Loops
- Functions
- Arrays
- Strings
- Pointers
- Structures
- Memory Concepts
- Bitwise Operators
- Embedded C Concepts
- Practical Programming Exercises
